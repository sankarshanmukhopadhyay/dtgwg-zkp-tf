# Upstream synchronisation evidence

This directory records the fork's one-way relationship with `trustoverip/dtgwg-zkp-tf`. Detection, review and integration are distinct states. An observed upstream commit is not treated as reviewed or integrated until a maintainer-approved pull request records that decision.

The human-readable upstream project README is preserved at [`../UPSTREAM_README.md`](../UPSTREAM_README.md). The root [`../README.md`](../README.md) intentionally describes this fork rather than duplicating or modifying the upstream project narrative.

`checkpoint.json` records machine-readable synchronisation state. See [`../docs/governance/upstream-synchronisation.md`](../docs/governance/upstream-synchronisation.md) for authority, procedure and evidence rules.
