# Support

This repository is an implementation and interoperability fork, not the authoritative DTG ZKP specification or a production support service.

## Use GitHub issues for

- reproducible defects in fork-owned tooling, tests, fixtures or documentation;
- implementation-guide ambiguity;
- conformance-harness defects;
- evidence or interoperability gaps that are within this repository's scope;
- proposals for bounded experimental implementation work.

## Route elsewhere when appropriate

Questions or proposed normative changes to the DTG ZKP specification belong with the authoritative upstream DTG ZKP Task Force. Credential, Registry, Trust Task, governance and other cross-specification semantics should be raised with their owning repositories rather than redefined locally.

Security-sensitive reports should follow [SECURITY.md](./SECURITY.md) and should not be disclosed publicly before assessment.

## Information to include

For technical support issues, include the affected commit/release, command or workflow, expected and observed behaviour, minimal reproduction steps, relevant logs with secrets removed, and whether the problem affects semantic conformance, construction evidence, interoperability evidence, documentation or deployment guidance.
