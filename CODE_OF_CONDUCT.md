# Code of Conduct

## Our standard

Participation in this repository should be professional, evidence-led and respectful. Disagreement about architecture, privacy claims, cryptographic constructions, governance boundaries or upstream direction is expected; personal attacks, harassment, discrimination, intimidation and deliberate disruption are not acceptable.

Contributors should critique propositions, evidence and implementation choices rather than people. Security or privacy concerns should be raised through the appropriate reporting channel rather than used to expose sensitive information publicly.

## Scope

This code applies to repository issues, pull requests, discussions, reviews and other project-managed collaboration surfaces.

## Enforcement

Repository maintainers may edit, remove or reject contributions that violate this standard; restrict participation; lock discussions; or escalate platform-abuse concerns to GitHub where appropriate. Enforcement decisions should be proportionate and should not be used to suppress good-faith technical or governance disagreement.

Reports about conduct may be made privately to the repository owner. Do not include unrelated sensitive personal information.
