# Validation and taxonomy framework

Stable identifiers allow scenarios, ADRs, matrices, and conformance tests to cross-reference
predicates, adversaries, horizons, lifecycle states, validation dimensions, roles, and failures.

The [Identifier and control register](../reference/identifier-register.md) is the reader-facing cross-document index for stable semantic IDs. Domain catalogues remain authoritative for their definitions.
